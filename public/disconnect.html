Disconnect Spotify

Effective 5 October 2026.

Local logout and removal of Spotify account permission are separate actions.

1. End this tab's local session

Use Logout in the app, or the button below. This clears Spotify credentials and login data in this tab. Visiting this help page has already left the app workspace and discarded its in-memory search results and draft. Use Logout in other open Jammming tabs too.

2. Remove account-level permission

  1. Open Spotify's Apps page and log in if asked.
  2. Find the developer app you authorized for Jammming; its name may match the developer dashboard registration.
  3. Select Remove Access.

Removing permission prevents further authorized use by this app. Logout alone does not revoke that permission. Neither action deletes playlists already created in Spotify; manage those in a Spotify client. Cancellation cannot undo requests already processed, so inspect Spotify if you left during a save.

For browser-storage problems, clear this site's stored data in browser settings. See Spotify's official help.
